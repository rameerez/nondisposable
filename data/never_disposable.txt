# Domains that are NEVER disposable, whatever any blocklist says.
#
# A false positive is a real person who cannot sign up, so this list outranks
# every upstream source and the host's own `additional_domains` (see the
# precedence table in the README). It protects each domain's whole namespace:
# `bak.rr.com` is covered by `rr.com`.
#
# Effective set at runtime = this file + data/email_providers.txt, minus
# data/privacy_relays.txt. Relays are deliberately NOT here: whether to accept
# them is a policy (`config.block_privacy_relays`), and a permanent exemption
# would make `block_privacy_relays = true` silently do nothing.
#
# Every entry needs evidence. A domain listed here and later shown to be a
# throwaway is a recall bug; a real provider missing from here is a lockout.
# Precision wins ties. Hosts add their own with `config.excluded_domains`.
