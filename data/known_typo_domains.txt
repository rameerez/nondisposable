# Reviewed typo domains, used by Nondisposable::KnownTypos.
#
#   <typo domain> <the provider it is a misspelling of>
#
# These are the ONLY lookalike domains the validator refuses outright (when
# `reject_lookalike_domains` is on). Everything else one edit from a provider
# is a guess, and a guess only ever produces a confirmable error. So the bar
# for an entry is high, and it is the same bar for every entry:
#
#   1. The domain is a misspelling of a provider in data/email_providers.txt.
#   2. There is direct evidence that nobody has a real mailbox there, of one of
#      these kinds:
#        - it redirects to the provider, or is held on the provider's own DNS
#          (a defensive registration: yaho.com, homail.com);
#        - it is parked or for sale through a parking/marketplace network
#          (nameservers or lander of parkingcrew, sedo, bodis, afternic,
#          above.com…), or publishes a Null MX (RFC 7505: "accepts no mail");
#        - it is a typosquat: it redirects visitors to an unrelated monetised
#          page, or its mail goes to a catch-all run for misspelled domains;
#        - it is registered but has no MX, A or AAAA record, so mail to it
#          cannot be delivered at all (RFC 5321 §5.1 has nothing to fall
#          back to). Every lookup must have answered NOERROR — recorded in the
#          evidence's dns_status column, and the labelling script refuses the
#          verdict otherwise — never inferred from a lookup that timed out.
#   3. The evidence is recorded, row by row, in test/fixtures/lookalike_corpus.csv
#      (collected by script/collect_lookalike_evidence.rb on 2026-10-17), and
#      the suite fails if an entry here loses its `typo` row there.
#
# What is NOT enough on its own: "no MX record" (SMTP falls back to the A
# record), a blank homepage, or a short name. When the evidence is ambiguous
# the domain stays OFF this list and remains confirmable — a wrong entry here
# is a person who cannot sign up and cannot say "yes, this is my address".
#
# Never generated, never bulk-imported. Add an entry with its evidence row.
